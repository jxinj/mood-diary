## 一、作品简介

「心晴手记」是一个把 **AI 情绪分析** 与 **个人心理记录** 结合的交互式网页应用。用户可以写下每天的心情日记，选择心情分与情绪强度，作品会：

1. 用本地情绪分析引擎识别文字中的情感倾向与主导情绪（喜悦 / 平静 / 焦虑 / 悲伤 / 愤怒 / 疲惫 / 感动）；
2. 生成有温度的共情回应和三条个性化小建议，建议可一键加入行动清单打卡；
3. 把日记保存在浏览器本地，并用心情曲线、日历热力图、情绪分布环与高频词云可视化情绪变化；
4. 自动生成「本周心情简报」，对比上周、总结主导情绪与高频词，一键复制；
5. 提供**情绪工具箱**：4-7-8 呼吸引导、5-4-3-2-1 着陆练习、小行动打卡与求助指引；
6. 支持**日间 / 夜间主题切换**与可选的**大模型 API 接入**（实验功能）。

所有数据只保存在用户自己的浏览器中，不上传服务器，不涉及任何账号系统。

## 四、运行说明（本地运行）

### 方式 A：直接打开（最简单）

双击 `index.html`，用浏览器打开即可使用全部功能（含情绪分析、本地存储、图表）。

### 方式 B：本地静态服务器（推荐，行为与线上一致）

在项目根目录执行以下任一命令，然后访问提示的地址：

```bash
# Python 3
python -m http.server 8000
# 访问 http://localhost:8000
```

```bash
# Node.js（若已安装 npx）
npx serve .
```

> 说明：方式 B 只是让浏览器以 `http://` 协议加载页面，与 GitHub Pages 环境一致；方式 A 也没有任何功能缺失（大模型 API 调用除外，它需要联网）。

## 五、使用流程

1. **写日记**：在「写日记」页选择心情、调整强度、写下想说的话（不知道写什么可点「换一个小问题」获取引导），可加标签或选择匿名模式；
2. **AI 分析**：点击「交给树洞分析」，即可看到识别出的情绪、心情温度、关键词、共情回应和三条建议；建议可「加入行动清单」；
3. **看趋势**：切换到「情绪趋势」，查看近 7 / 30 天的心情折线图、心情日历、情绪分布环、高频词云、统计卡片与本周心情简报；
4. **翻日记**：在「日记本」里按关键词或情绪筛选，可编辑、复制、删除历史记录，或导出 / 导入 JSON 备份；
5. **用工具箱**：在「情绪工具箱」做 4-7-8 呼吸、5-4-3-2-1 着陆练习，给小行动打卡，或使用日间 / 夜间主题；
6. **接大模型（可选）**：在「关于与设置」填入 OpenAI 兼容的 API 地址、Key 和模型名，保存后新日记将优先由大模型生成回应；留空则使用本地引擎。

## 六、技术原理（对应实验报告）

- **情感词典法**：内置 70+ 个带权重的正 / 负向情感词，对文本做极性打分；
- **否定与程度处理**：识别「不 / 没 / 很 / 非常 / 有点」等词，反转或增强情感权重；
- **情绪分类**：七类情绪关键词库累加得分，取最高分作为主导情绪并给出置信度；
- **加权心情分**：文本极性推算分数（40%）与用户自评分（60%）加权，避免误判；
- **生成式回应**：按主导情绪从模板库组合共情回应与建议，高强度情绪追加安抚语；
- **关键词提取与词云**：中文滑窗切词 + 停用词过滤，对近 30 天日记统计词频并渲染为词云；
- **周报生成**：按近 7 天 / 前 7 天对比心情分，汇总主导情绪与高频词，生成一段可复制的简报；
- **大模型增强**：可选调用 OpenAI 兼容 API，用系统提示词约束"共情、具体、不说教、不给医疗诊断"。

## 七、部署到 GitHub Pages

> 课程要求：网页项目必须部署到 GitHub Pages 且链接可正常访问，仅上传代码不算完成部署。

### 步骤

1. 注册 / 登录 [GitHub](https://github.com)，点击右上角 **`+` → New repository**；
2. 仓库名建议填写 `<你的用户名>.github.io` 的独立仓库，或任意名称（如 `mood-diary`）作为项目站点；
3. 把本目录下所有文件上传到仓库根目录（`index.html` 必须在根目录）；
4. 进入仓库 **Settings → Pages**；
5. **Build and deployment** 中：
   - Source 选择 **Deploy from a branch**；
   - Branch 选择 `main`，文件夹选择 `/ (root)`；
   - 点击 **Save**；
6. 等待 1–2 分钟刷新页面，顶部会出现绿色访问链接：
   - 独立仓库：`https://<用户名>.github.io/`
   - 项目仓库：`https://<用户名>.github.io/mood-diary/`
7. 用手机或另一台设备打开链接确认可访问，把该链接填入实验报告封面的「成果链接」，并提交仓库地址。

### 更新站点

之后每次修改代码，只需把变更提交（`git commit` + `git push`）到 `main` 分支，GitHub Pages 会在几十秒内自动重新发布。

### 常见问题

| 问题 | 解决 |
| --- | --- |
| 页面 404 | 确认 `index.html` 在仓库根目录，且 Pages 的 Branch 选的是 `/ (root)` |
| 样式丢失 | 检查 `css/`、`js/` 文件夹是否一并上传，引用路径大小写是否一致 |
| 一直显示部署中 | 首次发布通常需要 1–2 分钟，请耐心等待后刷新 |
| 大模型无响应 | 确认 API 地址是 OpenAI 兼容格式、Key 有效，或直接用本地引擎（功能完整） |

## 八、隐私与伦理说明

- 日记、设置均通过浏览器 `localStorage` 存储，**不会上传服务器**；清除浏览器数据会丢失记录，请定期导出 JSON 备份；
- 作品定位是情绪记录与陪伴，**不是心理治疗工具**；若长期情绪低落，请及时寻求专业心理咨询或医疗帮助；
- 大模型 Key 仅保存在本机浏览器，公共设备上请勿启用大模型功能。
