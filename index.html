⚙️ 关于与设置

关于这个作品，以及你数据的去向。

这个作品做了什么

「心晴手记」是一个 AI + 心理健康的交叉类网页作品。它用本地情绪分析引擎识别日记中的情绪关键词与情感倾向，结合你选择的心情分与强度，生成有温度的共情回应与个性化建议；所有日记保存在浏览器本地，并通过心情曲线、日历热力图、情绪分布环与高频词云呈现情绪变化。此外还提供情绪工具箱（4-7-8 呼吸、5-4-3-2-1 着陆练习、小行动打卡）与每周心情简报，让记录不止于"看见"，更能"照顾"。

作品无需后端即可完整运行，因此可直接部署到 GitHub Pages。如果你想体验大模型驱动的回应，也可以在下方填入兼容 OpenAI 格式的 API 地址与密钥（实验用途，请勿在公共设备保存密钥）。
